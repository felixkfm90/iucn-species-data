# Arten-Explorer-Appsymbol

Felix hat dieses Motiv am 26. Oktober 2026 als App-Logo angenommen und anschließend einen
transparenten Außenbereich sowie eine weiße Flugzeugturbine verlangt.

- `arten-explorer.png` ist die bytegleiche, korrigierte RGBA-Ausgabe mit 1.254 × 1.254 Pixeln.
  Außerhalb der schwarzen abgerundeten Fläche ist der Hintergrund transparent.
- `arten-explorer-transparent.ico` enthält 16, 24, 32, 48, 64, 128 und 256 Pixel als verlustfrei
  gespeicherte PNG-Einzelbilder. Alle sieben Größen behalten den Alphakanal; die Größenumrechnung
  verwendet Lanczos ohne Beschnitt. Der eigene Dateiname vermeidet den alten Windows-Symbolcache.
- Das korrigierte PNG hat SHA-256 `63922bd5c1735dd4a31aa4d7c721adf2d16cc1b2a8082bf41f55403a6d22651e`.

Die Dateien gehören zur lokalen Desktop-Hülle. Die Website und ihr FN-Logo sind unabhängig davon.
`desktop/main.mjs` bindet das Fenstersymbol, `desktop/install-shortcut.ps1` das Symbol einer bewusst
neu eingerichteten Desktop-Verknüpfung. Vorhandene Verknüpfungen werden durch eine Quelländerung nicht
automatisch überschrieben.
